# Frequently Asked Questions

This section answers common questions about large language models (LLMs), AI agents, AI security, and MLOps in modern software delivery environments.

These FAQs focus on **understanding concepts and their implications for CI/CD and software delivery**. They help contributors and practitioners build a shared mental model before exploring implementation details.

## Where to find more information

The documentation follows the [Diátaxis documentation framework](https://diataxis.fr/), which separates content by its purpose.

- **Explanation:** Explore concepts, architectural decisions, and trade-offs in `docs/explanation/`.
- **How-to guides:** Find practical, task-oriented instructions in the relevant how-to sections.
- **Reference:** Find technical specifications, configuration details, terminology, and API information in `docs/reference/`.

For shared terminology, see the [AI Glossary](../../reference/ai_glossary.md).

For deeper conceptual material, explore the [LLM explanations](../llm/) and [agent explanations](../agents/) directories.

These FAQs are an initial index of frequently encountered questions. Their coverage can evolve as the documentation and the needs of contributors and practitioners develop.
